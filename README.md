# Aurevio

Aurevio is an independent frontend portfolio built with semantic HTML, CSS and vanilla JavaScript. The site uses a pre-rendered page structure so the core content is available immediately without waiting for JavaScript to fetch sections.

## Stack

- Vite for development and production builds
- HTML for page structure and content
- CSS for layout, typography, responsive behavior and motion styling
- Vanilla JavaScript for navigation, reveals, scroll progress and lightweight pointer/scroll interactions

## Development

Requires Node.js 20+.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Content

Page sections live in `sections/`; Vite expands their include markers in `index.html` into one pre-rendered page.

## Deployment

GitHub Actions builds the Vite project and deploys `dist/` to GitHub Pages whenever `main` changes.

## Accessibility

The site includes a skip link, semantic headings and sections, labelled navigation, keyboard-friendly controls, descriptive project image alt text, touch-safe mobile navigation, and reduced-motion handling.

## UI checks

```bash
npx playwright install chromium
npm run build
npm test
```

The smoke checks launch a local production preview and cover package selection,
keyboard navigation, anchor alignment, both themes, seven viewport widths, image
loading and navigation without JavaScript. Set `AUREVIO_TEST_URL` to check an
already running preview, or `AUREVIO_CHROMIUM_PATH` to use an existing Chromium.

## Digital studio experiment

This branch turns Aurevio into a full-screen Three.js walkthrough through one modeled studio building. Native scrolling and the destination buttons move a camera through the entrance, gallery, workshop and other spaces. The existing semantic portfolio remains available through **Simple view**, and is the default if WebGL is unavailable, JavaScript is disabled, reduced motion is requested or data saving is enabled. The building is generated by `scripts/build_studio_model.py`, loaded only for the enhanced experience, and its project textures load near the gallery. The scene redraws on changes rather than running continuously.

Run `npm install`, `npm run dev`, and open the local address Vite prints. `npm run build` produces the GitHub Pages build; `npm run test:studio` checks camera interpolation, the building file, navigation logic and simulated inquiry states. `npm test` runs the existing browser suite and needs a working Playwright-compatible Chromium installation. Browser testing and actual Formspree delivery verification are still required before treating this experiment as production-ready.
