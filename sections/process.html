The process

Good work,
no black box.

You know what is happening, what is changing and what is getting shipped.

  1. 01START

    Talk

    Goals, audience, pages and what the site actually needs to accomplish.

  2. 02PLAN

    Shape

    Structure, content and visual direction before the code gets messy.

  3. 03BUILD

    Develop

    Responsive HTML, CSS and JavaScript built around the approved direction.

  4. 04FINISH

    Launch

    Polish, test real screen sizes, fix the annoying bits, then ship.
